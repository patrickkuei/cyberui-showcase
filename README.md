# cyberui-showcase

Real-world example apps built with [cyberui-2045](https://github.com/patrickkuei/CyberUI) — showing what you can actually build, not just a component inventory.

## Demos

| Demo | Status |
|------|--------|
| AI SaaS dashboard | planned |
| Landing page / marketing site | planned |
| Mobile-first app | planned |
| Community / social interface | planned |

## Get just one demo

Each demo package is self-contained — you don't need to clone this whole repo:

```bash
npx tiged patrickkuei/cyberui-showcase/packages/<demo-name> my-app
cd my-app && npm install && npm run dev
```
